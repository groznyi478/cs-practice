Рабочая папка — это файлы проекта, которые находятся у меня на компьютере.

Индекс — промежуточная область между рабочей папкой и историей Git.

Коммит — это сохранённая точка в истории проекта.

Git — это программа для отслеживания изменений в коде на вашем компьютере, а GitHub — это сайт в интернете для хранения этого кода и командной работы

git diff - изменения в рабочей папке, которые не были добавлены с помощью git add, а git diff --staged - добавленные изменения, которые попадут в следующий коммит

Использованные команды: 

1. git status

Показывает текущее состояние рабочей директории и индекса.

2\. git diff

Показывает изменения в рабочей директории, которые ещё не добавлены

в индекс.

3\. git diff --staged

Показывает изменения, подготовленные в индексе для следующего коммита.
