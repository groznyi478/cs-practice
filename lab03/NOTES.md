



 Сравнение команд



 git diff



`git diff` показывает различия между состояниями файлов.



Обычный `git diff` показывает незакоммиченные изменения

в рабочей директории.



 git show



`git show` показывает конкретный коммит: его информацию и изменения,

которые он внёс.



 git log



`git log` показывает историю коммитов.



 git log -S"def"



Команда ищет коммиты, в которых изменилось количество вхождений

строки `def` в указанном файле.



 git blame



`git blame` показывает, каким коммитом была добавлена или изменена

конкретная строка файла.




Восстановление файла



`git restore lab03/calc.py` восстанавливает файл из текущего `HEAD`.



`git restore --source=HEAD\~2 lab03/calc.py` восстанавливает файл

из указанного старого коммита.



При этом история коммитов не изменяется: изменяется только содержимое

файла в рабочей директории.



Если после этого сделать commit, восстановленная старая версия станет

частью нового коммита.







 Revert



`git revert` создаёт новый коммит, который отменяет изменения

предыдущего коммита.



Ошибочный коммит при этом не удаляется из истории.



`git reset --hard` работает иначе: он перемещает указатель ветки

и может удалить коммиты из текущей линии истории, а также отбросить

незакоммиченные изменения.



Поэтому для отмены уже опубликованного ошибочного коммита безопаснее

использовать `git revert`, не переписывая историю.




 Tag и branch



Tag — это имя конкретной версии проекта. Например, `v1.0`

указывает на определённое состояние проекта.



Branch — это отдельная линия разработки. Новые коммиты продолжают

двигать указатель ветки.



Поэтому tag удобен для обозначения релизов, а branch — для разработки

и экспериментов.







 Экспериментальная ветка



Ветка `experiment` использовалась для безопасного добавления

деления с проверкой деления на ноль.



Изменение было сделано не непосредственно в `main`.



После проверки ветка была объединена с `main` командой:



   git merge --no-ff experiment



Опция `--no-ff` заставила Git создать отдельный merge-коммит,

сохранив факт существования экспериментальной ветки в истории.
